## ⭐ Contribución destacada

Uno de los proyectos en los que he realizado una **contribución importante** es la plataforma de la **Red de Colegios Amigos del Turismo (CAT)**.

Es un proyecto web orientado a la gestión y presentación de contenidos de la red de instituciones vinculadas al turismo educativo en Colombia.

**Tecnologías y herramientas utilizadas:**

* React
* TypeScript
* Payload CMS
* PostgreSQL
* Docker
* Git / GitHub
* Diseño y desarrollo de interfaces web
